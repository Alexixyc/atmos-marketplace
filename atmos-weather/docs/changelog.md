# 版本记录

## 1.1.3 · 2026-10-02

- 修复插件详情页「打开插件」这一全局入口中，城市照片与影片被宿主不透明 `body` 背景盖住的问题。此前媒体能够加载、播放和更新时间尺，但位于负层级的风景没有独立堆叠上下文；新版将风景限制在应用自己的上下文中。
- 保持 1.1.2 的媒体策略：内嵌默认影片读取已发布 `v1.1.1` 标签的固定 HTTPS 副本，独立 Web 播放包内本地文件。影片内容和素材地址未变。
- 界面资源更新为 `ui://atmos/weather-1.1.3.html`，随插件版本隔离。

更新后刷新 Codex，关闭已经打开的天气页面，再从插件详情页「打开插件」或新聊天重新进入，确认侧栏显示 `v 1.1.3`。原生聊天面板已实测显示照片与 4K 影片；本次全局入口复现和修复验收见[播放复验](video-playback-verification.md)。

## 1.1.2 · 2026-10-02

- 修复纽约影片在内嵌视图中的加载路径：已核实的官方宿主 `26.928.21956` 会过滤 HTTP loopback 媒体 origin 并阻止请求；1.1.1 实际已打包完整的 62,676,514 字节影片，问题并非缺少文件。
- MCP Apps 改用 `raw.githubusercontent.com` 上固定 `v1.1.1` 标签的 HTTPS 副本，与包内影片 SHA-256 相同；独立 Web 继续播放本地文件。内嵌首次使用需预留约 63 MB 网络流量，实际取决于 Range 与缓存。
- 明确区分加载中、加载失败和减少动态效果；首次加载累计前台可见等待 20 秒仍未就绪时保留照片与天气，并提供重试和独立网页播放本地影片的入口。
- UI resource URI 随插件版本变化，避免升级后复用旧 HTML 缓存。

固定 HTTPS 影片的真实 Range 请求已返回 206，独立 Web 播放已验证；原生 MCP Apps 图形播放尚未现场验收。更新后请刷新 Codex，在新聊天选择插件再打开纽约。加载方式与验证边界见[影片说明](manhattan-video.md)。

## 1.1.0 · 2026-10-02

- 根据真实当前天气呈现晴空、多云、阴天、雾、雨、雪、雷雨七类效果；支持关闭动态效果、系统减少动态效果和后台暂停。
- 调整十座精选城市在手机、桌面和超宽屏中的裁切焦点，改进玻璃卡片、侧栏、边缘高光和间距。
- 纽约内置用户提供的 4K AI 曼哈顿延时影片，打开后定位到当地时间对应画面；时间尺支持悬停、拖动和键盘选时，可播放、暂停与回到此刻。光影为艺术化示意，天气保持真实数据。
- 从原片整理为均匀 24 fps，保留全部 577 个不同画面帧；修复重复取帧造成的卡顿，减少被遮住底图的绘制，改善播放游标过渡。
- 修复切换城市后地址仍指向旧城市的问题；刷新与分享链接恢复当前城市。视频资源加入内容版本，避免沿用旧媒体缓存。
- 插件当时通过本地媒体服务流式读取视频，支持 Range 请求；视频无法加载时恢复照片，天气查询继续可用。该内嵌 loopback 方案的宿主限制在 1.1.2 中修正，Web 本地播放仍保留。
- 修复升级时复用旧版本 Web 服务的问题；首选端口被占用时，在其他本机端口启动当前版本，并返回对应界面链接。

影片为 3840 × 2160、约 24 秒、无声 H.264 MP4，约 62.7 MB，随发行包提供；来源和修改记录见[影片说明](manhattan-video.md)。相关截图、测试结果及验证范围见 [UI 验收](ui-refinement-verification.md)和[播放复验](video-playback-verification.md)。独立 Web 入口已实际验证；原生 MCP Apps 视频视图未完成视觉验收。

已安装用户执行以下命令，然后刷新 Codex、打开新聊天并选择插件：

```bash
codex plugin marketplace upgrade atmos-local
codex plugin add atmos-weather@atmos-local
```
