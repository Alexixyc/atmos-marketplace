## 来源与处理

用户使用 Seedance 生成 720P 影片，完成 4K 升级后提供给本项目。输入文件已是 3840 × 2160；此次接入保留该分辨率，没有重新进行 AI 放大，也不将其标为原生 4K 摄影。参考照片为 Giuseppe Milo 的 [Manhattan Skyline at sunset - New York](https://commons.wikimedia.org/wiki/File:Manhattan_Skyline_at_sunset_-_New_York.jpg)，采用 [CC BY 2.0](https://creativecommons.org/licenses/by/2.0/)；影片基于照片生成、改变光照、水面与云层，并经过升分辨率和重新编码。照片作者不代表为本应用背书。

原文件约 155.8 MB，含音轨；容器标称 60 fps，但实际平均约 24 fps。当前网页版本统一为恒定 24 fps、H.264 / yuv420p，移除音轨，每秒设置关键帧并将 MP4 索引放在文件头，便于加载和时间尺取帧。原文件未改动。

本轮从原片重新生成均匀 24 fps 的网页版本，保留 4K 原片全部 577 个不同画面帧。此前 30 fps 版本有 722 帧，其中 145 帧为重复画面；本次去掉这些重复帧，按原有画面顺序均匀排布，没有生成插值帧。输出仍为 3840 × 2160，时长约 24 秒。

## 界面行为

- 纽约自动加载内置影片。默认定位到当地时间对应的画面；无需重复选择文件。
- 横屏居中等比铺满；竖屏焦点为 `70% 50%`，保留世贸中心一号楼。焦点记录在影片索引中。
- 时间尺将 06:00 至次日 06:00 等比例映射到影片；悬停和拖动连续选时，键盘每次调整 15 分钟。选时只改变风景，真实天气和当地时钟保持原数据。
- 「播放光影」从当前选时继续播放，进度同步到时间尺。「回到此刻」暂停并回到当地当前时间对应的画面。
- 视频表现晨光、暖日光、黄昏和夜色。它没有逐帧的真实时间记录；时间尺是艺术化映射，并不模拟纽约当天的精确日出日落。
- 首尾的颜色、亮度和云层不匹配，不能无缝循环。片尾停在次日 06:00，用户再次播放时从片头开始。
- 页面隐藏、关闭动态城市风景或系统减少动态效果会停止连续播放；仍可手动选取静态帧。
- 播放资源失败时回到原有照片，保留天气查询。设置中的「重试影片」重新加载。
- 「更换视频」仅创建当前会话的本地覆盖；设置中的「恢复默认」或刷新页面恢复内置影片。

视频画面可见后隐藏下层照片，减少同时绘制的内容。时间尺定位完成后，允许浏览器停在目标时间附近的实际帧边界，避免因时间戳的细小差异重复触发同一目标的定位。

## 构建与插件

Vite 将视频原样复制到 `dist/videos/`；`npm run package:plugin` 会检查文件存在并复制到插件的 `dist/videos/`。视频不内嵌到 MCP HTML 或编码为 base64。

每次替换视频内容时，同步将资源 `src` 的 `v` 参数更新为新文件 SHA-256 的前 12 位（当前为 `f29fabd4e327`），让浏览器使用新 URL 隔离 MP4 分段缓存。

MCP Apps 的 HTML 引用插件启动的本地 HTTP 媒体服务，CSP 仅加入该服务的精确 origin；HTTP 支持 MP4 byte-range 请求。即使先读取 UI resource、未调用打开工具，也会尝试启动媒体服务。服务启动失败时仍可返回照片界面；视频失败不会阻塞天气工具。

已用 MCP SDK 客户端验证资源 URL、CSP、206 Range 响应，以及端口占用时的照片回退。实际视频解码和交互验收在本地 Web 页面完成；尚未验证 Codex 原生 MCP Apps 视图对本地视频的播放策略。可用本地 Web 链接打开相同界面。

1.1.0 发行另修复服务复用：仅复用插件与影片内容版本一致的服务，首选端口被占用时改用系统分配的空闲本机端口。资源 URL、CSP 和打开工具返回的链接共用实际 origin；仅在服务仍无法启动或视频加载失败时回退照片。相关升级回归见[发行复核](video-playback-verification.md)。
