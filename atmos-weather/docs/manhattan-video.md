接入日期：2026-10-01。当前加载方案：1.1.2（2026-10-02）。资源索引为 `shared/timelapses.ts`，城市 ID 为 `newyork`，发行资源为 `public/videos/newyork-daycycle-4k.mp4`。

## 来源与处理

用户使用 Seedance 生成 720P 影片，完成 4K 升级后提供给本项目。输入文件已是 3840 × 2160；此次接入保留该分辨率，没有重新进行 AI 放大，也不将其标为原生 4K 摄影。参考照片为 Giuseppe Milo 的 [Manhattan Skyline at sunset - New York](https://commons.wikimedia.org/wiki/File:Manhattan_Skyline_at_sunset_-_New_York.jpg)，采用 [CC BY 2.0](https://creativecommons.org/licenses/by/2.0/)；影片基于照片生成、改变光照、水面与云层，并经过升分辨率和重新编码。照片作者不代表为本应用背书。

原文件约 155.8 MB，含音轨；容器标称 60 fps，但实际平均约 24 fps。当前网页版本统一为恒定 24 fps、H.264 / yuv420p，移除音轨，每秒设置关键帧并将 MP4 索引放在文件头，便于加载和时间尺取帧。原文件未改动。

1.1.0 发布前从原片重新生成均匀 24 fps 的网页版本，保留 4K 原片全部 577 个不同画面帧。更早的 30 fps 版本有 722 帧，其中 145 帧为重复画面；整理时去掉这些重复帧，按原有画面顺序均匀排布，没有生成插值帧。输出仍为 3840 × 2160，时长约 24 秒；1.1.2 沿用相同影片。

## 界面行为

- 纽约自动加载预设影片。独立 Web 读取包内文件，MCP Apps 内嵌视图读取下文固定版本的 HTTPS 副本。默认定位到当地时间对应的画面；无需重复选择文件。
- 横屏居中等比铺满；竖屏焦点为 `70% 50%`，保留世贸中心一号楼。焦点记录在影片索引中。
- 时间尺将 06:00 至次日 06:00 等比例映射到影片；悬停和拖动连续选时，键盘每次调整 15 分钟。选时只改变风景，真实天气和当地时钟保持原数据。
- 「播放光影」从当前选时继续播放，进度同步到时间尺。「回到此刻」暂停并回到当地当前时间对应的画面。
- 视频表现晨光、暖日光、黄昏和夜色。它没有逐帧的真实时间记录；时间尺是艺术化映射，并不模拟纽约当天的精确日出日落。
- 首尾的颜色、亮度和云层不匹配，不能无缝循环。片尾停在次日 06:00，用户再次播放时从片头开始。
- 页面隐藏、关闭动态城市风景或系统减少动态效果会停止连续播放；仍可手动选取静态帧。
- 首次加载显示等待状态；累计在前台可见等待 20 秒仍未就绪时，显示失败与重试入口。页面不可见的时间不计入这一等待预算。
- 播放资源失败时回到原有照片，保留天气查询。「重试影片」重新加载；内嵌视图还提供独立网页入口，通过本机服务播放包内影片。
- 「减少动态效果」只限制连续播放，与正在加载、加载失败分别提示；仍可手动选取静态画面。
- 「更换视频」仅创建当前会话的本地覆盖；设置中的「恢复默认」或刷新页面恢复内置影片。

视频画面可见后隐藏下层照片，减少同时绘制的内容。时间尺定位完成后，允许浏览器停在目标时间附近的实际帧边界，避免因时间戳的细小差异重复触发同一目标的定位。

## 构建与插件

Vite 将视频原样复制到 `dist/videos/`；`npm run package:plugin` 会检查文件存在并复制到插件的 `dist/videos/`。视频不内嵌到 MCP HTML 或编码为 base64。

每次替换视频内容时，同步将资源 `src` 的 `v` 参数更新为新文件 SHA-256 的前 12 位（当前为 `f29fabd4e327`），让浏览器使用新 URL 隔离 MP4 分段缓存。

1.1.2 的 MCP Apps HTML 使用 `embeddedSrc`，固定指向已经发布的同一影片：

[固定 v1.1.1 影片地址](https://raw.githubusercontent.com/Alexixyc/atmos-marketplace/v1.1.1/atmos-weather/dist/videos/newyork-daycycle-4k.mp4)

该副本与包内文件的大小、SHA-256 完全一致，插件升级到 1.1.2 不代表影片内容改变。CSP 的 `resourceDomains` 只开放 `https://raw.githubusercontent.com`。首次内嵌使用需要联网，请预留约 63 MB 视频流量，实际传输量取决于 byte-range 请求与宿主缓存。远程地址不可达时保留照片，用户可以重试，或通过「本地播放链接」复制网址到浏览器播放本地文件。视频不通过天气数据源传输。

根因核实：官方桌面宿主 `26.928.21956` 会过滤 MCP Apps 的 HTTP loopback `resourceDomains` 并阻止请求。1.1.1 包内确实已有 62,676,514 字节影片，不是漏打包；原先在 MCP HTML 中加入本地媒体 origin 的方案已由 1.1.2 的 HTTPS 路径修正。UI 资源也改为按插件版本命名（当前 `ui://atmos/weather-1.1.2.html`），避免宿主沿用旧 HTML 缓存。

已验证固定 HTTPS 地址的真实 Range 请求返回 206，独立 Web 的视频解码和交互正常。原生 MCP Apps 图形播放尚未现场验收，不能据此宣称已实机播放。

更换影片时，先发布包含新文件、可公开读取的固定 Git 标签或提交，核对 HTTPS Range 与内容 SHA-256，再更新 `embeddedSrc`；不要直接引用会变化的 `main`，也不要让应用指向尚未发布的标签。同步更新本地 `src` 的内容版本与本说明，已发布标签不移动。详细顺序见[发布指南](releasing.md)。

历史记录：1.1.0 修复了 Web 服务复用，只复用插件与影片内容版本一致的服务，首选端口被占用时改用系统分配的空闲本机端口；当时 MCP 影片 URL、CSP 和 Web 链接共用本地 origin。Web 的复用修复仍保留，内嵌影片的旧 loopback 路径已在 1.1.2 改为 HTTPS。历史升级回归见[发行复核](video-playback-verification.md)。
